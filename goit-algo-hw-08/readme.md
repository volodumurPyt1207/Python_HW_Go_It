# goit-algo-hw-08

Домашня робота до тем 7 та 8: дерева та купи. Усі завдання зібрано у файлі `goit-algo-hw-08.py`.

```bash
python goit-algo-hw-08.py
```

## Завдання 1. Найменше значення в дереві

Функція `find_min(root)` спускається лівими гілками AVL-дерева до крайнього лівого вузла. У двійковому дереві пошуку саме там лежить найменший ключ. Складність O(log n), бо AVL-дерево збалансоване. Для порожнього дерева функція повертає `None`.

## Завдання 2. Сума всіх значень у дереві

Функція `tree_sum(root)` рекурсивно додає значення поточного вузла до сум лівого та правого піддерев. Кожен вузол вона відвідує один раз, тому складність O(n). Для порожнього дерева сума дорівнює `0`.

## Завдання 3. З'єднання кабелів з мінімальними витратами

Функція `min_cost_to_connect_cables(lengths)` використовує мінімальну купу (`heapq`) і на кожному кроці з'єднує два найкоротші кабелі, а результат повертає в купу. Довгі кабелі в такому разі потрапляють до суми витрат якомога менше разів, тому загальні витрати мінімальні. Складність O(n log n).

Приклад для кабелів `[8, 4, 6, 12]`:

| Крок | З'єднання | Витрати |
|---|---|---:|
| 1 | 4 + 6 | 10 |
| 2 | 8 + 10 | 18 |
| 3 | 12 + 18 | 30 |
| | **Разом** | **58** |
